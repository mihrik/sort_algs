# Sort Algs

## Описание

Проект содержит собственную реализацию стандартной функции qsort и тестирование этой функции на произведении "Евгений Онегин" А.С. Пушкина
в переводе на английский язык.

## Возможности

- Обработка аргументов командной строки, один из которых содержит название файла для тестирования
- Тестирование текста, сравнивая буквенные символы строк с помощью функции qsort и моего аналога quick_sort, также сортировка к исходному
  с помощью сортировки указателей
- Печать результатов этих сортировок на экран или в файл

## Фичи

- Защита аргументов командной строки от изменения с помощью использования 'const char * const'
- Контроль разыменовывания нулевого указателя при возможности передаче его через assert
- Использование массива структур, содержащих содержимое строки и её длину
- Использование единого буффера для хранения содержимого файла
- Использование единого массива структур со всеми строками и их длинами
